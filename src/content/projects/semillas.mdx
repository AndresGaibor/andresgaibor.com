## Qué demuestra

Capacidad para pensar un producto de extremo a extremo: UX, frontend, backend, datos, seguridad, PWA y evolución del modelo de contenido.

## Aprendizajes

- Modelar actividades sin duplicar lógica fue el mayor desafío de dominio.
- Separar estudiantes de administración desde el modelo de datos facilitó todo lo posterior.
- PWA con sync no es trivial — requiere planificar el modelo de datos para conflictos.
